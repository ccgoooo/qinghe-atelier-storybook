# qh-robots-s2-r2

A multi-page website for Qinghe Atelier, a fictional small brand.

The site includes home, about, products, and contact pages. Its contact form collects a name, email, and message, then displays a success message after submission. The site uses placeholder text and images.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://qinghe-atelier-storybook.lovable.app
